# Prior Auth Demo (Mock C)

Clickable prototype of the prior authorization workflow for the ATI RFP. All data is synthetic. Nothing connects to a payer.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The app is a single React component in `src/App.jsx`. It keeps all state in memory, so reloading the page resets the demo.
